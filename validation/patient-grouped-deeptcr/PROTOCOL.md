# Patient-separated DeepTCR sequence classifier

We test how well a large DeepTCR sequence classifier ranks responders among held-out CAR-T patients in the original archived 34-patient cohort. It uses the official PyPI DeepTCR 2.1.29 source, the original processed CSV with its archived binary labels, and the beta CDR3, beta V/J and constant dummy-alpha representation used in the historical run. DeepTCR’s 40-residue limit excludes three of the 239,637 archived sequence records. All 34 patients remain.

## Splits and model

- Reproduce the audit’s five stratified splits using sorted patient IDs and seed 20261120. Every patient contributes to one outer test fold. Patient IDs and sequences stay local. The split code checks group separation and complete out-of-fold coverage.
- Fit the V/J vocabulary on each fold’s training rows. DeepTCR independently encodes amino acids with the package’s fixed alphabet. Test genes absent from training use DeepTCR’s unknown category.
- Train the official `DeepTCR_SS._build` graph with `Run_Graph_SS`, two softmax classes, Adam, the large CNN, a batch size of 1,024 and 10 fixed epochs. The historical script supplied numeric `Y` to an API that selects regression. This rerun explicitly supplies binary class labels. Train on all eligible rows of each training fold, without early stopping or hyperparameter selection. Constant dummy-alpha inputs preserve the original architecture and never vary by patient.
- Produce one inference pass on each test fold after epoch 10. The equal-row mean of the responder-class sequence scores defines each patient’s score. Each patient contributes one score. The training objective weights rows equally, so patients with larger repertoires contribute more to that objective.
- The primary endpoint is within-fold AUROC, with equal weight for each eligible responder/nonresponder comparison. This keeps comparisons inside a single fitted model. Report pooled across-fold patient AUROC and average precision separately. Report the fraction correct at the prespecified 0.5 threshold descriptively. Note class prevalence and the number of patient comparisons.
- Quantify uncertainty with a patient bootstrap stratified by fold and class, conditional on the fitted predictions. Report a within-fold label-permutation control on the frozen predictions using 4,999 replicates to describe how unusual the fitted comparison count is under that reference. Because a patient’s outcome can enter other folds’ training, this is a fixed-score diagnostic for the trained models. Separately retrain fold 1 for the same number of epochs after shuffling labels among its training patients, preserving the number of assigned responders and nonresponders. Score that control against the true fold-1 test labels. Report it as a diagnostic on a single fold.

The run used local TensorFlow 2.12.0 for Apple Silicon. The original NVIDIA/Colab hardware differs. The archived data lack external validation, and 34 patients limit precision. The 10-epoch budget and within-fold rank metric were fixed before reading held-out scores. A compute smoke test may run on training rows before the held-out experiment. This is the official sequence classifier with patient aggregation. DeepTCR_WF would require a separate experiment with its repertoire-level objective.
